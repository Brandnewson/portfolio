## Hard rules — never break these
- SCSS only. No Tailwind. No inline styles. No CSS-in-JS.
- All colours via CSS custom properties defined in src/styles/_tokens.scss
- Islands (interactive) live in src/islands/ and use .tsx
- Static components live in src/components/ and use .astro
- lookup_table.json is auto-generated by CI — never edit or commit it manually
- Never add a dependency without checking if the native browser API or a smaller alternative covers it
- Every new interactive element needs a (i) TechNote entry in src/content/tech-notes/

## Branson's working style
Branson wants to understand what is being built and why at each step.
Before writing code, briefly explain: what this file does, why it is structured this way, and what to watch out for.
After writing code, flag anything Branson should review or make a decision on — especially aesthetic and UX choices.
Do not make sweeping style decisions silently. Propose, explain, then implement.
