## DeepSeek V3

**Base URL:** https://api.deepseek.com/v1
**Model:** deepseek-chat
**Endpoint:** POST /chat/completions

### Request shape

```typescript
{
  model: 'deepseek-chat',
  stream: true,
  max_tokens: 120,           // Keep tight — 2-3 sentences max
  messages: [
    { role: 'system', content: systemPrompt },
    { role: 'user', content: `Tell me about Branson's experience with: ${query}` }
  ]
}
```

### System prompt template

```
You are a knowledge index for Branson's professional background.
You have access to the following knowledge entries:

${relevantEntries}

Rules:
- Be specific and factual — name actual projects, companies, and contexts
- Connect dots across domains where they genuinely exist
- Keep responses to 2-3 sentences maximum
- Never invent connections that are not in the knowledge entries above
- Always refer to "Branson" in third person, never "I"
- Write as if narrating a portfolio, not answering an interview question
```

### Response (streamed SSE)

```
data: {"choices":[{"delta":{"content":"Branson"},"index":0}]}
data: {"choices":[{"delta":{"content":" developed"},"index":0}]}
...
data: [DONE]
```

### Pricing
~$0.000008 per query at 120 max_tokens. Negligible.

## Cloudflare Worker — DeepSeek Proxy

**Route:** POST /api/deepseek
**Deployed via:** wrangler (see wrangler.toml)

### Request from browser

```typescript
fetch('/api/deepseek', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    query: string,
    relevantEntries: KnowledgeEntry[]  // from Tier 1 search results
  })
})
```

### Worker response

```
Content-Type: text/event-stream
Transfer-Encoding: chunked

data: {"token": "Branson"}
data: {"token": " developed"}
...
data: {"done": true}
```

### Rate limiting

KV namespace: RATE_LIMIT
Key pattern: `ip:${clientIP}:${hourTimestamp}`
Value: request count
Limit: 10 requests per IP per hour
On exceed: returns 429 with `{"error": "Rate limit exceeded"}`

### Environment variables (set in Cloudflare dashboard, not in code)

```
DEEPSEEK_API_KEY=sk-...
RATE_LIMIT_PER_HOUR=10
```

## Pre-computed embeddings

Generated at build time using OpenAI text-embedding-3-small.
Stored in src/data/embeddings.json.

### Schema

```typescript
interface EmbeddingEntry {
  id: string           // matches knowledge entry slug
  embedding: number[]  // 1536-dimensional vector
}
```
